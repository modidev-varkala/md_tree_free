# MD_TreeFree (QGIS plugin)

Click a tree in aerial imagery; its whole crown is outlined as a polygon.

- Left click: capture crown  |  Right click: delete crown under cursor
- Settings: Plugins > MD_TreeFree > settings
- Output: "Tree crowns" polygon layer (or the active polygon layer) with `area_m2`

Install from ZIP or from the QGIS Plugin Repository.
